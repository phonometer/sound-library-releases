# Sound Library — Free SFX Library Manager

Sound Library is a free local sound effects library manager for Windows and macOS, built for game audio and sound designers.
Search, preview, and organize large SFX libraries, then select the exact region you need on the waveform and drag only that region directly into your DAW or NLE.

A lightweight alternative to Soundly for managing your own local SFX, Foley, field recordings, and audio libraries.

Source code is private. This repository hosts release binaries only.

## Features

- **Instant Search** — Search filenames, BWF metadata, tags, and custom descriptions together.
- **Waveform Preview** — Preview long SFX and Foley files without opening your DAW.
- **Region Selection** — Select only the part of a sound you need.
- **DAW / NLE Drag & Drop** — Drag the whole file or only the selected waveform region into supported applications.
- **Large Libraries** — Designed for large local collections, including 250k+ files.
- **Tags & Collections** — Organize sounds without moving or duplicating the original files.
- **Exclude Syntax** — Use `-word` to remove unwanted results from searches.
- **Local by Design** — Your audio files remain on your computer and are never uploaded.
