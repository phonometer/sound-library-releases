# Sound Library — Releases

Downloads for **Sound Library**, a local sound-effect library manager for Windows (Electron).

Source code is private. This repository hosts release binaries only.

## Download

See the [Releases](../../releases) page for the latest Windows installer and portable build.

## What it does

- Fast filename/path/tag search
- Instant waveform preview and playback
- Tags and Collections for organizing your library
- Native drag-and-drop into your DAW
- Rescan folders to pick up new files

Your sound library stays on your computer — files are indexed locally, never uploaded.
