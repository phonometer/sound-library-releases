# Sound Library — Releases

Sound Library is a free local sound effects library manager for game audio and sound designers.
Search, preview, organize, and drag sound effects directly into your DAW or NLE. Select a specific region on the waveform and drag only that part into your timeline.

A lightweight Soundly alternative for managing your own local SFX, Foley, field recordings, and audio libraries.

Source code is private. This repository hosts release binaries only.

## Download

- [itch.io page](https://mira-sound.itch.io/sound-library-sfx-manager) — full feature list, screenshots, and "name your own price" download
- [Releases](../../releases) — direct download of the latest Windows and macOS builds

Windows 10/11 (64-bit) and macOS 11+ (Apple Silicon).

## What it does

- Instant search across filename, path, tags, embedded BWF metadata, and hand-written descriptions — even on 250,000+ file libraries
- Exclude syntax ("-word") to cut noise from search results
- Auto-detected category tags (impact, whoosh, explosion, and more) surfaced live from your current search results
- Waveform preview with playback
- Select a region on the waveform and drag just that part — or the whole file — straight into Premiere Pro, CapCut, Cubase, Pro Tools, and other DAWs/NLEs
- Tags and Collections for organizing your library
- Rescan folders to pick up new files
- Built for large libraries: virtualized list, no practical file-count ceiling

Everything runs 100% locally — your files stay on your computer and are never uploaded.
